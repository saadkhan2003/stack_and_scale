# Auth Brand Notes (WS10)

- Sign-in inherits the existing Stack & Scale identity: dark petrol/night surfaces (`--ss-color-night`), solar accents (`--ss-color-solar`), sand text (`--ss-color-sand`).
- Tone: quiet, operational, secure. No marketing energy — the page should feel like a doorway, not a landing page.
- Voice: direct instructions ("Sign in to Stack & Scale."), no exclamation, no promises about features behind the gate.
- Trust signals are factual only: OIDC via Keycloak, activity logging. No fake badges or lock icons beyond standard affordances.
