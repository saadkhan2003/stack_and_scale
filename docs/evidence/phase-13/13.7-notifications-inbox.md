# Phase 13.7 Evidence

Implemented a tenant-scoped staff notification inbox with durable read state,
category, urgency, same-workspace deep links, deduplication and email delivery
state. The additive migration is `0006_staff_notifications.sql`.

Authorization uses `notification:read` and `notification:manage`; every role
can access only its own records in the configured organization. Critical and
security notices bypass preferences, are always queued through the existing
outbox, and security preferences cannot be disabled. The staff page is
`/staff/notifications`.

Focused API and web verification is recorded by the notification integration
tests and proxy tests. Full lint, typecheck, tests, format check and build are
run as part of the phase handoff.
