# Phase 13.8/13.9 Evidence

Implementation adds tenant-scoped knowledge CRUD and aggregate operational
reports without a paid platform. Authorization occurs before data retrieval;
knowledge mutations and report downloads emit audit events. Search receives
only the knowledge title/body mirror and applies the existing organization
filter. Report exports are bounded to 92 days and exclude lead PII.

The current-scale export is synchronous and capped at 92 days; the API rejects
invalid timestamps, invalid IANA timezones, non-positive windows, and windows
longer than 92 days. Missing dates default to the previous 30 days ending now,
and all query timestamps are interpreted as instants. CSV requires
`report:export`; JSON requires `report:read`.
