## Sound cues

The `minimal` pack is used for this operational SaaS workspace. Navigation and search use `select`/`open`/`close`; access outcomes use `unlock`, `blocked`, and `error`; sign-out uses `lock`. Audio is created only from a user gesture, remains silent until unlocked, and the preference is stored in local storage.
