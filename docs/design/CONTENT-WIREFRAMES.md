# Content Wireframes

## Home

Navigation → product-led hero → connected-system visual → capability choices → trust statement → contact CTA.

## Solution detail

Navigation → audience/problem statement → what the solution changes → proof/media → contextual CTA → related content.

The template must also support a missing proof block, a single related item, and an empty related-content state without leaving a visual gap.

## Service detail

Navigation → business outcome → engagement path → relevant projects → project CTA.

## Work

Navigation → concise client/context → problem → delivered system → measurable outcome or qualitative proof → related solution → project CTA.

## Resources

Navigation → filters/search → result list → individual resource → contextual product or service CTA. Empty filters explain that no result matched and offer a clear reset.

## Contact and form

Contextual CTA → short contact form → inline validation → sending state → success confirmation. Error states keep entered values and provide a recovery action; they never imply that a request was received unless it was.

## Work and resources

Both remain CMS-backed routes for Phase 06/07. Their templates must tolerate no items, short copy, long titles, missing optional media and deferred publication.
