# 15.4 Commercial Documents And Files

## Outcome

Expose customer-safe proposals, contracts, invoices, receipts and deliverables
without granting payment authority or leaking internal commercial/file metadata.

## Inputs and dependencies

- Source decisions: 46, 51, 56, 59, 65, 70, 84, 88-89.
- Predecessors: `15.0-contract-freeze`, `15.1-access`.
- Inputs: canonical Phase 14 commercial/file records and frozen visibility rules.

## Ownership and compatibility

- Owns: portal commercial/file projection services, DTOs, routes and tests.
- Prohibited: invoice/payment verification, reconciliation, storage keys,
  canonical artifacts and scanner/retention implementation.
- Output: read-only financial views, payment instructions, receipts and
  authorized short-lived file capabilities.
- Impact: additive portal APIs; Phase 14 remains the system of record.

## Actions and verification

1. Serialize only approved field allow-lists.
2. Authorize customer/project access before issuing a signed URL and audit it.
3. Apply quotas, type restrictions and scan-state checks through Phase 14 hooks.
4. Test internal-field absence, revoked access, expired links and cross-tenant
   document/file identifiers.
- Evidence: `docs/evidence/phase-15/15.4-commercial-files/`.
- Security: financial/contract downloads require fresh sensitive sessions.
- Capacity/cost: cap file sizes/transfers and measure connection/disk impact.
- Rollback: independently disable commercial or file flags and stop new URLs.
- Merge order: after `15.1`; frozen contract version required.
