implementation boundary.

- Source decisions: 15, 17, 28-43, 46, 51, 56, 59, 65, 70, 79, 84, 88-89.
- Predecessors: none.
- Inputs: Phase 14 records, `PORTAL-SHARED-CONTRACTS.md`, Phase 15 plan, and

- Owns: `docs/architecture/PORTAL-SHARED-CONTRACTS.md` and this phase plan.

2. Resolve every pending field in the approval record and set a contract

4. Verify every later step uses only the frozen contract version.
- Evidence: `docs/evidence/phase-15/15.0-contract-freeze/`.
- Security: approvals must affirm the no-leak and no-shadow-record rules.
- Capacity/cost: document $0 initial platform delta and capacity inputs.

- Merge order: first; contract version is assigned here.
