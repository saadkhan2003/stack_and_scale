# Step 13.1 — Staff Workspace Shell

## Outcome

Provide an authenticated, role-aware staff shell around the existing CRM route.

## Predecessors

None. Consume existing Phase 05 and Phase 09 contracts.

## Owned files

- `apps/web/app/staff/**`
- `apps/web/src/staff-*.tsx`
- staff-specific web tests and evidence

## Prohibited writes

- `packages/database/migrations/**`
- `packages/contracts/src/authorization.ts`
- CRM authorization service and state transitions

## Actions

- Add staff navigation and explicit loading, forbidden, degraded and error
  states.
- Preserve server-side/session authorization; UI hiding is not authorization.
- Add accessible navigation and a command-search entry point.

## Verification

```text
npx pnpm --filter @stack-and-scale/web lint
npx pnpm --filter @stack-and-scale/web typecheck
npx pnpm --filter @stack-and-scale/web test
```

## Security and rollback

Test anonymous, member-only and manager access. Disable the staff route if the
shell fails; public lead intake remains unaffected.
