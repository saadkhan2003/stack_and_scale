# Step 13.6 — Authorized Global Operations Search

## Outcome

Provide a staff search entry point for permitted leads, tasks, internal content
and documents using bounded PostgreSQL queries.

## Security and performance

- Authorization is resolved before the query executes.
- Every source is filtered by the resolved organization ID.
- Results are limited to 25 and queries are limited to 100 input characters.
- Only a short document excerpt is returned; document bodies and sensitive
  fields are never returned as search results.
- No counts, suggestions or result existence are returned for unauthorized
  sources.

## Verification

API integration tests cover cross-organization filtering and web tests cover
cookie-preserving proxy behavior and degraded upstream handling.
