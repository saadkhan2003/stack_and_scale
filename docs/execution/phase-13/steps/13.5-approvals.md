# Step 13.5 — Generic Approvals

## Outcome

Provide a tenant-scoped approval primitive for high-impact operations with
requester, approver, decision, reason, expiry and immutable audit records.

## Authorization

`owner` and `admin` may decide approvals. `owner`, `admin` and `manager` may
request and read approvals. Members have no approval access. The API resolves
the organization and role from the existing membership policy; request input
cannot select a tenant or authorize an action.

## Safety rules

- Expired and already-decided requests cannot be changed.
- Requesters cannot approve their own request.
- Decision reason is required and bounded.
- Schema changes are additive and migration-safe.

## Verification

API integration tests cover authorization, separation of duties, expiry-ready
state handling, and audit trail writes.
