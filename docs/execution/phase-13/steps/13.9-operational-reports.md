# Step 13.9 - Operational Reports

Reports are aggregate-only and run synchronously at current scale. The API
accepts `funnel`, `response-time`, `workload`, `conversion`, or `activity`,
optional ISO timestamps, an IANA timezone, and `json` or `csv` format. Defaults
are the previous 30 days in UTC; windows must be positive and no longer than
92 days. CSV requires `report:export`; JSON requires `report:read`.

Formulas:

- Funnel: current lead count grouped by stage for leads created in the window;
  stage history is not available in the current schema.
- Response time: average minutes from lead creation to first lead activity;
  leads without an activity are excluded.
- Workload: tasks created in range grouped by assignee; `completed_at IS NULL`
  is open.
- Conversion: won leads / all leads by source x 100.
- Activity: lead activity count grouped by activity type.

Report results contain no lead names, emails, messages, or attribution. Every
export is tenant-filtered and audit recorded. A future async export can be
introduced when measured volume exceeds this synchronous bound.
