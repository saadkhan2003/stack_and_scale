# 18.2 — protected aggregate capture

- **Outcome:** a protected manual workflow writes/validates one baseline record.
- **Inputs:** frozen field allowlist and existing production deployment secrets.
- **Owns:** Phase 18 baseline workflow only.
- **Prohibited:** application APIs/schemas, customer data, new credentials,
  external services and deployment changes.
- **Actions:** capture only declared aggregates, retain 90 days, validate the
  JSON shape, and use production-environment protection/concurrency.
- **Verification:** formatting check plus protected workflow run.
- **Evidence:** `docs/evidence/phase-18/production-baseline/`.
- **Capacity/cost:** tiny local files, $0 incremental cost.
- **Rollback:** remove the workflow and isolated evidence directory.
