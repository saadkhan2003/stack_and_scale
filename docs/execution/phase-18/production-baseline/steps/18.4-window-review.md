# 18.4 — baseline-window review

- **Outcome:** validate retained aggregate records and report evidence maturity
  without treating same-day samples as a production window.
- **Inputs:** protected-host baseline JSON records produced by `18.2`.
- **Owns:** the baseline workflow review action and Phase 18 evidence.
- **Prohibited:** raw record export, customer-data collection, new storage,
  application changes and automatic advanced-capability activation.
- **Actions:** validate every record against the frozen allowlist; return only
  sample count, distinct-day count, oldest/latest day and maturity state.
- **Verification:** manual protected review against the existing records.
- **Evidence:** `docs/evidence/phase-18/production-baseline/VERIFICATION.md`.
- **Capacity/cost:** bounded local reads only; $0 incremental cost.
- **Rollback:** remove the review action; existing captures remain isolated.
