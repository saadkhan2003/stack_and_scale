# 16.3 — entitlement resolver and snapshots

## Outcome

Resolve versioned plan entitlements, add-ons and overrides into deterministic,
time-bounded organization snapshots for downstream product runtimes.

## Inputs and ownership

- Sources: decisions 012, 031, 033, 079, 084, 085 and frozen `16.0–16.2`.
- Owns: entitlement schema, resolver, snapshot API/event contract and tests.
- Prohibits: product runtime authorization internals, payment mutation and
  license signing secrets.

## Actions and compatibility

1. Define precedence and effective-date logic for plan, add-on, override and
   grace states.
2. Return a signed/versioned snapshot payload suitable for cached product use.
3. Keep the resolver pure and deterministic for the same inputs/time.

## Verification and evidence

- Test reproducibility, precedence, expiry, cross-tenant denial and control
  plane outage/grace simulations.
- Evidence: `docs/evidence/phase-16/16.3-entitlements/`.
- Capacity/cost: cache snapshots and rate-limit reads; $0 change.
- Rollback: serve last valid bounded snapshot; disable new override issuance.
- Merge: after `16.2`; exports the entitlement snapshot version.
