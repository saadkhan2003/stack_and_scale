# 17.2 Signed event delivery

- **Outcome:** durable signed envelope, recipient delivery state, retry/DLQ and replay.
- **Sources / predecessors:** 049, 073, 079; 17.0–17.1.
- **Owns:** integration event tables/service/worker and contract tests.
- **Must not write:** generic CRM/webhook schemas or consumer product data.
- **Verification/evidence:** signature tamper, duplicate, unordered, retry and
  replay tests in `docs/evidence/phase-17/17.2-events/`.
- **Security/capacity/cost/rollback:** public keys only, bounded backoff/attempts;
  $0; pause consumers without deleting durable events; contract `1.0`.
