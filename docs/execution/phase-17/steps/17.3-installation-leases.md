# 17.3 Installation trust and leases

- **Outcome:** rotating installation credentials and signed, anti-rollback leases.
- **Sources / predecessors:** 031, 046, 082–085; 17.0–17.1.
- **Owns:** integration credential/lease tables and integration service routes.
- **Must not write:** Phase 16 signing secret storage or shared identity schema.
- **Verification/evidence:** provision, rotate, replace, revoke, expiration,
  old-lease replay and key-compromise tests in `17.3-installation-leases/`.
- **Security/capacity/cost/rollback:** hashes only, MFA staff recovery, five-minute
  skew, bounded grace; $0; disable enforcement separately; contract `1.0`.
