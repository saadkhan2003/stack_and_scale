# Step 14.1 — Shared Commercial Primitives

## Outcome

Define reusable provider-neutral money, tax, document-version and state helpers.

## Predecessors

Phase 13 complete in code. Phase 12 launch approval remains separate.

## Constraints

- Store amounts in integer minor units with explicit ISO currency.
- Use decimal-safe arithmetic and deterministic rounding.
- Keep tax rates/configuration jurisdiction-owned, never hard-coded as truth.
- Issued records are immutable; corrections create compensating records.
- Do not enable payment or e-sign providers in this step.

## Verification

Test currency mismatch, rounding boundaries, negative/zero amounts, tax
configuration, document version immutability, numbering uniqueness and state
transitions.
