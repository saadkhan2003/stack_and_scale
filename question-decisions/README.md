# Stack & Scale — 100 Architecture Question Decisions

This directory contains one detailed Markdown record for each question from the Stack & Scale architecture interview.

Each record contains:

- the normalized final question and selected direction;
- the concise rationale, benefits, tradeoffs and implementation phase;
- the full corresponding brainstorming discussion from the source conversation;
- the options and recommendation that were considered;
- the user's response, including clarification exchanges;
- the final explanation and resolution;
- an interpretation rule for AI-assisted implementation.

Where a later conversation refined an earlier answer, the later decision is authoritative.

## Recommended AI reading order

1. Read [`STACK_AND_SCALE_PLATFORM_BLUEPRINT_V1.md`](../STACK_AND_SCALE_PLATFORM_BLUEPRINT_V1.md) for the consolidated target architecture.
2. Read this index and the relevant numbered question files for detailed intent and tradeoffs.
3. Treat **Your chosen direction** in each file as authoritative.
4. Use the full brainstorming section to understand why the decision was made, not as permission to implement every alternative discussed.
5. Respect the implementation phase so future capabilities do not inflate the first release.
